##### TM

##### A crucial understanding lies at the framework's core: knowing why you need a solution. TGF delivers a clear and direct message—don't build a solution in search of a problem. Inspired by Simon Sinek's "Start with Why," the framework consists of three layers: the why, how, and what. Each layer encompasses various tools, methods, and approaches that align with its specific goal.

The Grounded Framework Tools
----------------------------

The TGF framework consists of three layers, starting with "why". Each layer contain various tools that can be utilised through workshops or consultation. Since TGF is not a rigid, one-size-fits-all framework, organisations can use different tools from each layer.​
