# NPC Property Dashboard Security Implementation Plan

Detailed security assessments, unresolved findings, affected component inventories,
and remediation sequencing are maintained in the restricted security program rather
than this repository. Authorized maintainers should use that program as the source
of truth and follow the repository's security contribution guidance in
`AGENTS_NPC_Property_Dashboard.md` when implementing an approved work package.

Do not add active vulnerability details, production security posture, exploit paths,
credentials, or internal remediation timelines to this public document. Report new
security concerns through the project's private security-reporting channel.
